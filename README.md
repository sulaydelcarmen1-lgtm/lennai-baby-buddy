# LennAI: Your Gentle Guide

Crea una aplicación web mobile-first llamada LennAI, diseñada para acompañar y apoyar a madres primerizas. La experiencia debe sentirse cálida, reconfortante, moderna y muy fácil de usar.

Diseño: utiliza una paleta suave de colores pastel inspirados en bebés: rosa bebé, azul cielo, lavanda, amarillo crema y blanco. Usa bordes redondeados, sombras suaves y pequeños elementos decorativos como nubes, globos, estrellas y moños, sin sobrecargar la interfaz. El estilo debe ser premium, elegante y acogedor.

Funcionalidades principales:

Registro e inicio de sesión.

Onboarding para solicitar fecha de nacimiento o edad del bebé, tipo de alimentación y preferencias.

Inicio personalizado mostrando: “Tu día con tu bebé”, edad actual del bebé, próximas tareas y recomendaciones.

Registro de sueño, alimentación y pañales.

Sección de contenido personalizado según la edad del bebé.

Asistente LennAI, una IA para responder preguntas generales sobre maternidad y ofrecer recomendaciones personalizadas basadas en la información registrada.

Generador de rutinas diarias según la edad y necesidades del bebé.

Seguimiento de hitos del desarrollo.

Diario de recuerdos para guardar momentos especiales.

Sección “Para mamá” con mensajes de motivación y check-in emocional.

Panel de analíticas sencillas para visualizar patrones de sueño y alimentación.

Premium: crea una suscripción Premium de US$7 al mes con acceso a IA ilimitada, rutinas avanzadas, analíticas, automatizaciones y contenido exclusivo. La versión gratuita debe mostrar algunas funciones bloqueadas con un diseño atractivo que motive a actualizar. Incluye una pantalla clara para gestionar la suscripción y el pago con Apple Pay o tarjeta de crédito/débito.

Soporte: incluye un botón visible de “Soporte por WhatsApp” que abra una conversación con el número +1 820-990-3366.

Crea una interfaz inicial completa con navegación inferior: Inicio, Seguimiento, LennAI, Contenido y Perfil. Prioriza una experiencia mobile-first, intuitiva, emocional y profesional donde cada botón incluya su función.
